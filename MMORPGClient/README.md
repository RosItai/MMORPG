### setting up the client

if you dont have aioquic and pygame already, run this to install them WHILE INSIDE THIS FOLDER:
```bash
pip install -r requirements.txt
```

you could also install latest INSTEAD using:
```bash
pip install pygame
pip install aioquic
```

### running the client

running is as simple as

```
python3 client.py
```

make sure all servers are up and running beforehand!
